# 产品需求文档（PRD）—— 个人作品集网站

> 版本：v1.0 ｜ 状态：已实现并通过本地验证 ｜ 部署目标：Cloudflare Pages（D1 + Pages Functions）

## 1. 产品概述

复刻参考站 `https://myshow-bey.pages.dev/`（暗色单页个人作品集），构建一个**同时包含前台展示与后台管理**的个人网站。前台用于向访客展示个人信息，后台用于管理员在不改代码的前提下维护所有展示内容。整站部署在 Cloudflare Pages，配合 D1（SQLite）与 Pages Functions 实现零额外服务的全栈能力。

## 2. 目标用户

- **访客**：查看博主的个人介绍、技能、项目与博客。
- **站长（管理员）**：通过后台登录后，对全站内容进行增删改查、搜索、导出与改密。

## 3. 前台功能需求（严格四模块）

### 3.1 个人介绍（About / Hero）
- 展示：姓名、头衔/标语、头像（图片 URL）、个人简介、社交链接（GitHub / 邮箱 / 微博等，可多条）。
- 布局：首屏居中，头像圆形带光晕，社交按钮悬停发光。

### 3.2 技能展示（Skills）
- 数据：技能名称、分类（前端/后端/运维等）、熟练度（0–100）、排序权重。
- 展示：按分类分组，进度条动画填充。

### 3.3 项目展示（Projects）
- 数据：标题、描述、封面图（URL）、演示链接、仓库链接、标签（数组）、排序权重。
- 展示：响应式卡片网格，悬停放大并显示「演示/源码」按钮。

### 3.4 博客（Blog）
- 数据：标题、摘要、正文（纯文本）、发布日期。
- 展示：列表含日期徽标与摘要；点击打开居中模态框展示**纯文本**正文（无 Markdown 渲染、无独立文章页）。
- 支持按关键词搜索（标题/摘要/正文 LIKE 过滤）。

### 3.5 通用
- **主题**：默认暗色（贴合参考站），支持暗/亮一键切换并记住选择（localStorage）。
- **语言**：全站中文。
- **响应式**：桌面多列、移动端单列堆叠。

## 4. 后台功能需求

| 功能 | 说明 |
| --- | --- |
| 密码登录 | 单一管理员密码 + 会话 Cookie 鉴权，零外部依赖 |
| 个人介绍编辑 | 修改姓名/头衔/头像/简介/社交链接 |
| 技能 CRUD | 增删改查，按名称搜索 |
| 项目 CRUD | 增删改查，按名称搜索，标签以逗号分隔输入 |
| 博客 CRUD | 撰写/编辑/删除，按标题搜索，正文为纯文本 |
| 搜索筛选 | 各列表支持关键词实时过滤 |
| 修改密码 | 后台内修改管理员密码（≥6 位） |
| 数据导出 | 一键导出全站数据为 JSON 文件 |

## 5. 非功能需求

- **可部署性**：一键部署到 Cloudflare Pages，免费额度充足。
- **无状态鉴权**：用 HMAC 签名 Cookie，无需会话表。
- **安全性**：所有 DB 访问使用参数化 SQL（防注入）；密码以 PBKDF2+Salt 哈希存储；Cookie 为 HttpOnly。
- **性能**：读接口为单表查询；静态资源走 CDN；列表支持服务端 `?q=` 过滤。
- **可维护性**：前台/后台/API 清晰分层；新增模块沿用既有 CRUD 模式。

## 6. 数据模型（概要）

| 表 | 关键字段 |
| --- | --- |
| `profile` | id(=1), name, title, avatar_url, bio, social_links(JSON) |
| `skills` | id, name, category, level, order_index |
| `projects` | id, title, description, image_url, project_url, repo_url, tags(JSON), order_index |
| `blog_posts` | id, title, summary, content, published_at |
| `admin` | id(=1), password_hash |

## 7. 验收标准

1. 部署后前台完整展示四模块（含示例/真实内容）。
2. 博客列表可搜索，点击可查看纯文本正文。
3. 暗/亮主题切换生效并持久化。
4. 后台可用默认密码登录；未登录调用写接口返回 401。
5. 四模块均可增删改查；搜索、改密码、导出 JSON 均可用。
6. 静态资源与 `/api/*` 同源，无 CORS 问题。

## 8. 范围外（本期不做）

- 联系表单 / 留言（参考站未要求）。
- 图片上传到 R2（本期仅支持图片 URL）。
- 博客 Markdown 渲染与独立文章页（需求为纯文本查看）。
- 多管理员、OAuth、评论系统。
